# The State of AI in Visual Studio

**Session:** BRK017 | **Speakers:** [Rachel Kang](https://dotnet.microsoft.com/en-us/conf/2026/speakers/rachel-kang), [Barbara Boyajian](https://dotnet.microsoft.com/en-us/conf/2026/speakers/barbara-boyajian)

[Session details](https://dotnet.microsoft.com/en-us/conf/2026/agenda/brk017) | [Slides](https://github.com/rachelkang/talks/tree/main/2026-11-11%20The%20State%20of%20AI%20in%20Visual%20Studio)

## Abstract

Visual Studio brings new brains and more choice to AI-assisted development. Explore a new agent harness powered by the Copilot SDK, expanded access to models and providers, and greater control over configuration and how AI works for you. See how GitHub Copilot and other AI options bring more capable agents, greater choice, and the flexibility to shape AI around every stage of your .NET development workflow.
